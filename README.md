# hpbrn.com

The hpbrn website. Tools for lucidity and ways to connect.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- [Tailwind CSS](https://tailwindcss.com)
- [Geist](https://vercel.com/font)

## Develop

```bash
npm install
npm run dev
```

Then open [localhost:3000](http://localhost:3000).
